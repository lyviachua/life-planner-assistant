# Life Planner Assistant

All-in-one personal productivity planner combining scheduling, budgeting, daily task execution, Pomodoro cycles, and local Ollama AI advisory.

## Technology Stack

- **Frontend**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS + Lucide Icons
- **Routing**: React Router DOM v6

## Running the Application

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

## Application Routes

- `/` - Dashboard Overview
- `/calendar` - Month Grid Calendar
- `/day-planner` - 24-Hour Day Timeline
- `/tasks` - Tasks & Priorities
- `/expenses` - Finance & Budget Ledger
- `/notes` - Personal Markdown Notes
- `/pomodoro` - Focus Timer & Session Log
- `/settings` - Ollama AI & Preferences Configuration
- `/help` - Documentation & Setup Guide
